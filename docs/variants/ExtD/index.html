異体字(別字) CJK統合漢字拡張D

このページに掲載している異体字(別字)は、Unicode上は別のコードポイントを持つ独立した漢字ですが、由来や用法が同じ「異体字」として登録されているものです。

Unicode のブロックの1つである CJK統合漢字拡張D に含まれる漢字の異体字(別字)一覧です。 CJK統合漢字拡張D は追加漢字面 (第2面) の U+2B740-2B81D の範囲に定義されています。 異体字(別字)のデータは @marmooo/cjkvi-variants の異体字リストに基づいています。
