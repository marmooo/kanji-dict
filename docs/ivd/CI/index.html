異体字(字体) CJK互換漢字

このページに掲載している異体字(IVS)は、多くの環境では基底字と同じ字形で表示され、専用のフォントがないと区別が付きません。 区別できるよう、Jigmoフォントに収録されている字形を SVG として表示しています。

Unicode のブロックの1つである CJK互換漢字に含まれる漢字の異体字(IVS)一覧です。 CJK互換漢字は基本多言語面 (第0面) の U+F900-FAD9 の範囲に定義されています。 異体字の字体データは Jigmo フォントの収録内容に基づいています。
