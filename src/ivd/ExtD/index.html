異体字(字体) CJK統合漢字拡張D

このページに掲載している異体字(IVS)は、多くの環境では基底字と同じ字形で表示され、専用のフォントがないと区別が付きません。 区別できるよう、Jigmoフォントに収録されている字形を SVG として表示しています。

Unicode のブロックの1つである CJK統合漢字拡張D に含まれる漢字の異体字(IVS)一覧です。 CJK統合漢字拡張D は追加漢字面 (第2面) の U+2B740-2B81D の範囲に定義されています。 異体字の字体データは Jigmo フォントの収録内容に基づいています。
